# Personal Finance Advisor Bot — Design Brief

## Direction

### Calm Fintech Compass
A modern, clean, responsive fintech interface that makes money management feel steady and approachable rather than judgmental. The visual system uses calm blue and green as signals of clarity and progress, with warm neutral surfaces for focus.

Probability: 0.08 (selected because it directly follows the requested fintech direction)

## Expanded design system

- **Design movement:** Editorial fintech dashboard with quiet confidence, data literacy, and helpful coaching.
- **Core principles:** Make the next best action obvious; explain metrics in plain language; celebrate consistency over perfection; keep sensitive data visually calm.
- **Color philosophy:** Deep navy for navigation and trust, ocean blue for primary actions, mint/emerald for positive progress, amber for attention, rose-red only for urgent overspending, and a soft neutral background for breathing room.
- **Layout paradigm:** Desktop sidebar with a responsive top bar fallback; a dashboard hero row of KPI cards; modular two-column insights; dense data tables that collapse into cards on mobile.
- **Signature elements:** Rounded metric cards, thin progress tracks, category icon dots, friendly insight callouts, and a subtle compass/leaf mark that suggests direction and growth.
- **Interaction philosophy:** Sensitive financial actions wait for server confirmation; forms preserve input on validation errors; filters feel immediate; AI actions show explicit loading and fallback status.
- **Animation:** Restrained 160–220ms transitions for cards, progress bars, and navigation; no distracting loops; reduced-motion support.
- **Typography system:** A highly legible sans-serif stack with bold display numbers and compact labels; line-height generous enough for mobile scanning.
- **Brand essence:** A dependable co-pilot for everyday financial decisions.
- **Brand voice:** Friendly, non-judgmental, plainspoken, specific, and honest about uncertainty.
- **Wordmark/logo:** “finwise” wordmark paired with a flat compass-leaf symbol; use the product name in accessible text and the symbol in the favicon.
- **Signature brand color:** `#2B78E4` ocean blue, paired with `#17A673` emerald.

## Asset plan

Create one project-specific flat square icon with full-bleed ocean-blue background and a centered mint compass-leaf silhouette. Reuse the mark in the header and favicon. No generic stock imagery is needed because this is a data/control dashboard; charts and UI elements are the visual content.
